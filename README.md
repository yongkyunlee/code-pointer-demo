# Code Pointer demos

Runnable experiments accompanying [Code Pointer](https://codepointer.substack.com/).

- [2026-11 · Loop Transformer depth trace](2026-11-loop-transformer/) compares readouts after every block of a looped and a regular Transformer. [Interactive report](https://htmlpreview.github.io/?https://github.com/yongkyunlee/code-pointer-demo/blob/2e192997a45a779f2d2c3c2d3717a3948dec56bd/2026-11-loop-transformer/index.html)
- [2026-11 · Backend.AI introduction](2026-11-backend-ai-intro/) contains three scenarios: FIFO queue blocking, placement fragmentation, and automatic idle-session reclamation with persistent files.

Each scenario has its own runnable folder, instructions. Scenarios accompanying the same article share pinned dependencies and setup code.
