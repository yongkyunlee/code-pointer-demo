# Code Pointer demos

Runnable experiments accompanying [Code Pointer](https://codepointer.substack.com/).

- [2026-11 · Backend.AI introduction](2026-11-backend-ai-intro/) contains three scenarios: FIFO queue blocking, placement fragmentation, and automatic idle-session reclamation with persistent files.

Each scenario has its own runnable folder, instructions, and recorded evidence. Scenarios accompanying the same article share pinned dependencies and setup code.
