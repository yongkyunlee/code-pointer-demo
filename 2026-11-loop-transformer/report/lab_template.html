Companion lab · Loop Transformer experiments

Loop Transformer lab

A looped Transformer runs the same blocks again and again. A regular Transformer runs each block once. Three experiments changed one part of the forward pass in both kinds of model and recorded the answers. Each experiment below shows the setup, asks for a prediction, and then reveals the recorded run on a Kaggle T4.

Architecture

Two stacks

Ouro-1.4B has {{OURO_WIDTH}} blocks and runs all of them four times, for {{OURO_DEPTH}} executed blocks. Qwen2.5-1.5B has {{QWEN_DEPTH}} blocks and runs each one once. Both runs are split into four stages so the experiments can compare the same point in each model. In Ouro a stage is one pass through the shared stack. In Qwen a stage is a group of {{QWEN_WIDTH}} different blocks.

Comparisons that isolate weight sharing

Ouro and Qwen differ in more than weight sharing. They were trained on different data with different recipes, use different tokenizers, and execute {{OURO_DEPTH}} and {{QWEN_DEPTH}} blocks. A difference between the two checkpoints can come from any of these. The small training control changes only whether the blocks are shared, so it is the comparison that can attribute a difference to weight sharing on these synthetic tasks.

Experiment 1 · hidden-state swap

Carry and language

Can a carry transfer between sums while the answer stays in the recipient’s language?

Predict

Two sums that both equal 75

The models were asked for the tens digit of a sum as one word. In 28 + 47 the ones digits add to 15, so a 1 carries into the tens column. In 60 + 15 the ones digits add to 5, so nothing carries. Suppose 60 + 15 keeps its own tens digits, 6 and 1, but receives the carry from 28 + 47.

Which tens word should 60 + 15 write?

Intervene

Copy the donor’s hidden state

The run did not copy a carry bit. It copied the donor’s whole hidden state at the last prompt token, the colon after the language name, at the end of one stage. That vector can also hold the donor’s operands, its own answer and its language. The recipient then ran every remaining block with that one vector replaced.

The margin is the full-word log probability of “eight” minus that of “seven” after the prompt, in natural-log units. The change compares it with the same model’s clean prompt. A positive change moves the model toward the carry prediction. Words are recorded exactly as generated, so a malformed word appears as written.

Across 100 held-out families

Each family pairs a carry sum and a no-carry sum with the same total. The plot follows the donor and shows every copy stage. The clean prompt shows the same-language swap.

Recipient language

Can a reader find the carry at each stage?

A ridge reader fit on each stage’s states recovers the carry on most held-out prompts in both models. The same reader fit at stage 1 and reused at later stages falls to 50%, chance, in both models, even in Ouro where stages 2 to 4 rerun stage 1’s weights. Readable information did not translate into a carry-directed swap effect.

Experiment 2 · source-closed memory

Memory and belief

Can one stored memory preserve what Alice believes, what Bob believes, and where the coin actually is?

Predict

Held-out scene {{MEMORY_SCENE}}

People remember the last box where they saw the coin. Step through the story, then answer the three questions.

    Intervene

    Close the story after stage 2

    The prompt holds the story, then eight neutral token positions, then one question. In the full-story condition, the question can read every earlier token at every block. In the memory condition, the eight positions read the story during stages 1 and 2 while the question reads only itself. The run saved those eight states at the end of stage 2 and gave the same saved states to all three questions. In stages 3 and 4, the question can read the eight positions and its own words, and no position can read the story.

    Experiment 3 · attention cuts

    Repeated clue

    Does revisiting a block give the model a second chance to use an earlier clue?

    Predict

    Held-out locker scene {{LOCKER_SCENE}}

    The model reads the same record twice, then answers one question.

    Your answer

    Intervene

    Cut one attention connection at one visit

    A word can attend only to earlier words. The locker descriptions in copy 1 come before Tom’s clue, so they cannot read it. The same descriptions in copy 2 can read Tom’s clue in copy 1. The cut removes exactly those connections, from the copy-2 descriptions to the clue, at the chosen block visits. Every word stays in the prompt, and the question can still read both copies.

    Block attention at
    Clue to cut
    Prediction · how much will cutting the clue at both visits change apple’s lead over orange?
    Reveal

    Correct fruit’s lead and generated token

    The lead is the final logit of “apple” minus the logit of “orange”. A positive lead favors the correct fruit. The generated token is the model’s first choice across its full vocabulary.

    Second chance test

    A second chance would show up as an interaction. After the stage-2 cut removes the clue once, the stage-3 cut should cost more than it does on its own. The control repeats every cut on Amy’s clue, which does not answer the question.
